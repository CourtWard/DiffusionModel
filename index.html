Diffusion Model

An interactive simulation of diffusion and effusion at the particulate level.

Student Guides

This model is designed to allow for guided inquiry. Each guide linked below includes the diffusion model along with guidance on how to interact with the model. The goal of these guided inquiries is to discover various properties and behaviors of particles.
